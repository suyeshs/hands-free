# Staff Android App - Tauri Android Build

## Approach: Use Existing Tauri + React Codebase

### Separate Builds from Same Code

**YES** - You get separate builds from the same codebase:

```bash
# Desktop build (Windows, macOS, Linux)
bun tauri build
→ Produces: .exe, .dmg, .deb, .app
→ For: Restaurant owners/managers/staff on desktops

# Android build (Mobile)
bun tauri android build
→ Produces: .apk, .aab
→ For: Staff on personal Android devices

# Same codebase, different builds!
```

### Why Tauri Android?

✅ **Reuse Everything**
- Same React components
- Same TypeScript codebase
- Same Zustand stores
- Same SQLite database
- Same API services

✅ **Single Codebase, Multiple Targets**
- One codebase for Desktop + Android
- Share 90%+ of the code
- Maintain once, deploy everywhere
- Build for desktop: `bun tauri build`
- Build for Android: `bun tauri android build`

✅ **Tauri Native Features**
- Access to Android APIs via Rust
- SQLite already integrated
- WebSocket support
- File system access
- Secure storage (Keychain/Keystore)

✅ **Fast Development**
- No separate React Native project
- Just add mobile-responsive UI
- Build with `bun tauri android build`

**2.5 Platform Detection - Show Different UI**

There are two strategies for handling desktop vs mobile:

### Strategy A: Auto-Detect and Redirect (Recommended)
```tsx
// src/hooks/usePlatformDetection.ts
import { useEffect, useState } from 'react';
import { invoke } from '@tauri-apps/api/core';

export function usePlatformDetection() {
  const [platform, setPlatform] = useState<'desktop' | 'android' | 'unknown'>('unknown');

  useEffect(() => {
    const detect = async () => {
      try {
        // Ask Rust backend what platform we're on
        const result = await invoke<string>('get_platform');
        setPlatform(result === 'android' ? 'android' : 'desktop');
      } catch (err) {
        // If Tauri not available, assume web browser
        setPlatform('desktop');
      }
    };

    detect();
  }, []);

  return platform;
}

// In App.tsx
function App() {
  const platform = usePlatformDetection();
  const { user } = useAuthStore();

  if (platform === 'unknown') {
    return <LoadingScreen />;
  }

  if (platform === 'android') {
    // Show mobile UI
    return (
      <HashRouter>
        <Routes>
          <Route path="/login" element={<MobileLogin />} />
          <Route path="/" element={<MobileLayout />}>
            <Route index element={<Navigate to="/home" />} />
            <Route path="home" element={<StaffMobileHome />} />
            <Route path="salary" element={<StaffMobileSalary />} />
            <Route path="schedule" element={<StaffMobileSchedule />} />
            <Route path="attendance" element={<StaffMobileAttendance />} />
            <Route path="leave" element={<StaffMobileLeave />} />
            <Route path="profile" element={<StaffMobileProfile />} />
          </Route>
        </Routes>
      </HashRouter>
    );
  }

  // Desktop UI (existing)
  return (
    <HashRouter>
      <Routes>
        <Route path="/login" element={<Login />} />
        <Route path="/hub" element={<HubPage />} />
        <Route path="/pos" element={<POSDashboard />} />
        <Route path="/kitchen" element={<KitchenDashboard />} />
        {/* ... existing desktop routes */}
      </Routes>
    </HashRouter>
  );
}
```

### Strategy B: Separate Entry Points
Keep both UIs in same app, use platform-specific routing:

```tsx
// All routes in one app
<Routes>
  {/* Desktop routes */}
  <Route path="/hub" element={<HubPage />} />
  <Route path="/pos" element={<POSDashboard />} />

  {/* Mobile routes */}
  <Route path="/mobile" element={<MobileLayout />}>
    <Route path="home" element={<StaffMobileHome />} />
    <Route path="salary" element={<StaffMobileSalary />} />
  </Route>

  {/* Redirect based on platform */}
  <Route path="/" element={<PlatformRedirect />} />
</Routes>
```

### Add Rust Command for Platform Detection
```rust
// src-tauri/src/commands/platform.rs

#[tauri::command]
pub fn get_platform() -> String {
    #[cfg(target_os = "android")]
    return "android".to_string();

    #[cfg(target_os = "windows")]
    return "windows".to_string();

    #[cfg(target_os = "macos")]
    return "macos".to_string();

    #[cfg(target_os = "linux")]
    return "linux".to_string();

    "unknown".to_string()
}
```

Register in `src-tauri/src/lib.rs`:
```rust
mod commands;

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .invoke_handler(tauri::generate_handler![
            commands::platform::get_platform,
            // ... other commands
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

Rust command:

```rust
// src-tauri/src/commands/biometric.rs

use tauri_plugin_biometric::{BiometricAuth, BiometricError};

#[tauri::command]
pub async fn authenticate_biometric() -> Result<bool, String> {
    match BiometricAuth::authenticate("Authenticate to access staff app").await {
        Ok(_) => Ok(true),
        Err(BiometricError::UserCancel) => Ok(false),
        Err(e) => Err(format!("Biometric auth failed: {:?}", e)),
    }
}
```

Frontend:
```tsx
import { invoke } from '@tauri-apps/api/core';

const authenticateWithBiometric = async () => {
  try {
    const result = await invoke<boolean>('authenticate_biometric');
    if (result) {
      console.log('Biometric authentication successful');
      // Proceed with login
    }
  } catch (err) {
    console.error('Biometric auth failed:', err);
  }
};
```

**3.2 Push Notifications (FCM)**

Add to `Cargo.toml`:
```toml
[dependencies]
firebase-cloud-messaging = "0.5"
```

Rust command:
```rust
// src-tauri/src/commands/notifications.rs

use firebase_cloud_messaging::{Client, Message};

#[tauri::command]
pub async fn register_fcm_token(token: String, staff_id: String) -> Result<(), String> {
    // Save FCM token to database
    let db = get_database()?;
    db.execute(
        "UPDATE staff_users SET fcm_token = ? WHERE id = ?",
        params![token, staff_id],
    ).map_err(|e| e.to_string())?;

    Ok(())
}

#[tauri::command]
pub async fn send_push_notification(
    fcm_token: String,
    title: String,
    body: String,
) -> Result<(), String> {
    let client = Client::new();
    let message = Message::new(&fcm_token)
        .notification(title, body)
        .build();

    client.send(message).await.map_err(|e| e.to_string())?;
    Ok(())
}
```

## Advantages of Tauri Android

✅ **Code Reuse**
- 90%+ code shared between desktop and mobile
- Same components, stores, services
- No duplicate logic

✅ **Single Build System**
- `bun tauri dev` for desktop
- `bun tauri android dev` for Android
- Same bundler, same dependencies

✅ **Shared Database**
- Same SQLite schema
- Same Rust commands
- Same data models

✅ **Easy Maintenance**
- Fix bug once, works everywhere
- Add feature once, available on both
- Update dependency once

✅ **Native Performance**
- Rust backend (fast)
- WebView (lightweight)
- Direct SQLite access
- No JavaScript bridge overhead

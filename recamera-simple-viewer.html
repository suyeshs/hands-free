Seeed Studio reCamera Viewer

IP: 192.168.68.100

Note: The reCamera doesn't have built-in HTTP/RTSP streaming enabled by default. You'll need to access the camera through one of the methods below.

Quick Access

Open reCamera Web Interface Open Node-RED Editor

How to View the Camera Feed:

  • Option 1: Open the reCamera web interface above and navigate to the preview/camera section
  • Option 2: Use the Node-RED editor to create a custom flow that streams the camera
  • Option 3: Access via MQTT (port 1883) using the SSCMA protocol

Camera Information:

  • Device: Seeed Studio reCamera
  • Platform: SSCMA (SenseCraft Smart Camera Model Assistant)
  • Web Interface: http://192.168.68.100
  • Node-RED: http://192.168.68.100:1880
  • MQTT Port: 1883
  • API Port: 80

Embed reCamera in Your Application:

You can embed the camera interface using an iframe:

<iframe src="http://192.168.68.100" width="100%" height="600"></iframe>

Need Direct Streaming?

To enable RTSP or HTTP streaming, you'll need to:

  • Install a streaming plugin in Node-RED (node-red-contrib-camera or similar)
  • Configure the reCamera to publish frames via MQTT
  • Create a custom Node-RED flow to serve video frames over HTTP
  • Or use the reCamera SDK to access the video stream programmatically

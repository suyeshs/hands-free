# Restaurant Settings (India - Cafe)

Flexible restaurant configuration plugin designed for Indian cafes, coffee shops, and casual dining establishments.

## Features

- **Flexible Layout**: Balanced 4-tab interface for cafe operations
- **GST Compliance**: Standard CGST/SGST configuration
- **Optional Service Charge**: Typically 5% for table service
- **FSSAI Registration**: Food license compliance
- **Dine-in + Takeaway**: Supports both service models
- **Simplified Legal**: GSTIN and FSSAI required, PAN optional
- **Casual Atmosphere**: Optimized for relaxed cafe environments

## Target Restaurants

- Coffee Shops & Cafes
- Tea Lounges & Chai Bars
- Breakfast Cafes
- Bakery Cafes
- Casual Dining Cafes
- Bistros & Brasseries

## Compliance Requirements

### FSSAI License
Cafes must obtain FSSAI registration:
- **Basic FSSAI**: Small cafes < ₹12 lakhs/year
- **State FSSAI**: Medium cafes ₹12 lakhs - ₹20 crores/year
- **Central FSSAI**: Large chains > ₹20 crores/year

Display FSSAI number:
- On receipts
- At entrance
- On menu boards
- Online listings

### GST Registration
- **Mandatory**: If turnover > ₹40 lakhs/year
- **Voluntary**: Can register below threshold
- **GSTIN**: 15-digit identification number
- **Returns**: Monthly/quarterly filing required

### Optional Licenses
- **Liquor License**: If serving alcohol (beer/wine bars)
- **Music License**: If playing background music
- **Terrace Permit**: For outdoor seating
- **Trade License**: Local municipal requirement

## Best Practices

1. **Menu Pricing**: Keep prices simple and rounded for quick transactions
2. **Service Charge**: Clearly indicate if service charge is added
3. **FSSAI Display**: Prominently show license at entrance
4. **Takeaway Efficiency**: Quick billing for to-go orders
5. **Dine-in Comfort**: Comfortable seating for longer stays
6. **Wifi & Power**: Popular features for cafe customers
7. **Loyalty Programs**: Encourage repeat visits
